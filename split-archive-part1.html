How to extract split archives (.part1.rar, .7z.001, .z01)

You usually do not need to “join” split archives first. Put every part in the same folder, keep the original file names, and open the first part. An extractor that supports multi-part archives then reads the remaining parts in order. The built-in Files app on iPhone cannot extract split archives, so you need an app that supports them.

Split archive naming, and which file to open

Different tools name their parts differently, and the part you open depends on the scheme:

Example namesFormatOpen this
photos.part1.rar, photos.part2.rar …RAR (newer naming).part1.rar
photos.rar, photos.r00, photos.r01 …RAR (older naming).rar
photos.7z.001, photos.7z.002 …7z.7z.001
photos.z01, photos.z02 … photos.zipZIP.zip (keep the .z01 parts beside it)

Split ZIP is the odd one out: the last part carries the .zip name. Do not open .z01 directly; open the .zip that sits in the same folder.

Three rules that make it work

  1. Same folder for every part. If even one part is still in Downloads or in a different iCloud Drive folder, extraction stops part-way.
  2. Do not rename anything. A duplicate download often becomes “photos.part1 (1).rar”, and the extractor can no longer find the next part. Remove the extra “(1)” so the names match again.
  3. Start from the first part. Opening part2 or .002 either fails or gives you only some of the files.
If the parts live in iCloud Drive, a cloud icon means the file has not been downloaded to the phone yet. Tap it, wait for the download to finish, then open the first part.

Steps on iPhone (shown with Zipbox)

  1. Save every part from Mail or Safari into the same folder in the Files app.
  2. Check the names and sizes. Apart from the last one, the parts are usually close to the same size.
  3. Touch and hold the first part (.part1.rar, .7z.001 or .zip), choose Share, then pick Zipbox.
  4. When the file list appears, select what you need or extract everything.
  5. If the archive is password protected, you are asked for the password at this point.

Missing parts: what the errors mean

What you seeLikely causeFix
An error about the next volume not being foundA part is missing or in another folderMove every part into one folder
Extraction stops half-wayOne part did not finish downloadingRe-save the part that is noticeably smaller
“Corrupt” or CRC errorA part was damaged in transitAsk the sender to resend just that part
Nothing happens when you open the first partA file name was changedRemove “(1)” and restore the original name

The numbers tell you which part is missing. If you have part1, part2 and part4, then part3 is the gap. Asking the sender for “just part3 again” is quicker than having everything resent.

Frequently asked questions

Do I have to join the parts before extracting?

Usually not. Open the first part in an app that supports split archives and it reads the other parts in sequence.

Can I get some files out if one part is missing?

Files stored entirely before the missing part can sometimes be extracted, but that is not guaranteed. Getting the missing part resent is the reliable fix.

Can the iPhone Files app open a split ZIP?

A split ZIP made of .z01, .z02 and .zip files is not the same as a normal .zip. The Files app cannot extract it; use an app that supports split archives.

What is a file ending in .001?

Usually one piece of a file split by 7z or a splitting tool. If it ends in .7z.001, it is a split 7z archive, and you start from .001.
