LINE、Gmail 收到的 ZIP 在 iPhone 上打不開怎麼辦

LINE 或 Gmail 收到的 ZIP 打不開，大多是這三種情況：還沒存到「檔案」App、檔案沒下載完、其實根本不是 ZIP（是 RAR 或 7z）。一般的 ZIP 存進「檔案」App 後點一下就能解開。下面先用對照表從症狀找原因，再照順序檢查。

先存到「檔案」App（最多人卡在這一步）

在 LINE 聊天室或 Gmail App 裡，看不到 ZIP 裡面的內容。第一步是把它存到 iPhone 的「檔案」App。不同版本的畫面可能略有差異，但流程大致相同：

LINE

  1. 在聊天室點一下 ZIP 檔，讓它下載。
  2. 點畫面上的分享按鈕（方框加向上箭頭的圖示）。
  3. 選「儲存到檔案」，指定存放位置（例如「我的 iPhone」）。

Gmail

  1. 打開信件，點附件。
  2. 從分享按鈕選「儲存到檔案」。
  3. 選位置後按「儲存」。

存好後，到「檔案」App 點一下 .zip，旁邊出現同名資料夾就代表解壓成功。

檔名變亂碼怎麼辦

在 Windows 上把中文檔名的檔案壓成 ZIP，傳到 iPhone 或 Mac 解開時，檔名常會變成一串看不懂的符號。這是文字編碼不同造成的，裡面的資料通常沒有壞，照片、PDF 多半還是能正常打開。如果一定要正確的檔名，最穩的方法是請對方把檔名改成英數字，或改用 7z 等其他格式重新壓縮。

其實是 RAR、7z、分卷或有密碼

長按檔案→「簡介」，確認副檔名。如果是 .rar 或 .7z，「檔案」App 解不開；分卷和有密碼的檔案也各有對應的處理方式：

  • RAR、7z → iPhone 怎麼開 RAR、7z
  • 分卷 → 分卷壓縮檔怎麼合併解壓
  • 有密碼 → 有密碼的 ZIP 怎麼開

這些檔案需要用支援的 App，例如 Zipbox。Zipbox 支援 ZIP、RAR、7z 等 13 種格式，可以從「檔案」App、郵件或分享選單直接開啟。

檔案太大或已過期

LINE 傳送的檔案有保存期限，過期後可能就無法下載。Gmail 遇到超過附件大小上限的檔案時，可能會改成 Google 雲端硬碟連結寄出，這時要從連結頁面儲存。這兩種情況收件人自己無法解決，只能請對方重傳，或改用其他方式分享。

照順序檢查清單

  1. 有沒有存到「檔案」App
  2. 檔案大小跟對方說的差不多嗎
  3. 副檔名是 .zip 嗎（不是 .rar、.7z、.z01、.part1）
  4. 有沒有要求輸入密碼
  5. 保存期限或連結有沒有過期
  6. 如果只是檔名亂碼，裡面的檔案能不能打開

常見問題

LINE 聊天室裡能直接看 ZIP 內容嗎？

聊天室裡看不到內容，請先存到「檔案」App 再開。

Gmail 顯示無法預覽怎麼辦？

ZIP 通常不在 Gmail 的預覽範圍內，從分享按鈕存到「檔案」App 再打開即可。

存了卻找不到檔案？

在「檔案」App 的「瀏覽」裡，「我的 iPhone」和「iCloud 雲碟」都看看，也可以直接在搜尋欄輸入檔名。

檔名亂碼代表檔案壞掉了嗎？

大多只是檔名顯示錯誤，內容本身是正常的。
