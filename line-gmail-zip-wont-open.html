ZIP from Gmail won’t open on iPhone: causes and fixes

When a ZIP from Gmail or a messaging app will not open on iPhone, the cause is usually one of three things: it has not been saved to the Files app, the download did not finish, or it is not really a ZIP (it is a RAR or 7z). A normal ZIP opens for free: save it to Files and tap it. Use the table below to match your symptom, then work down the checklist.

Save it to the Files app (where most people get stuck)

Gmail and messaging apps do not show what is inside a ZIP. The first step is always to save it to the iPhone Files app. The exact buttons vary a little between app versions, but the flow is the same:

Gmail

  1. Open the email and tap the attachment.
  2. Tap the share button (the square with an upward arrow).
  3. Choose Save to Files, pick a location such as On My iPhone, and tap Save.

Messaging apps

  1. Tap the ZIP in the chat so it downloads.
  2. Use the share button on the file screen.
  3. Choose Save to Files and pick a location.

Then open Files and tap the .zip. If a folder with the same name appears next to it, extraction worked and you are done.

When the file names are garbled

If a ZIP is created on a computer that uses a different character encoding for file names, for example names written in Japanese, Chinese or another non-Latin script, the names can turn into strings of odd symbols when extracted on an iPhone or Mac. The data inside is almost always fine; photos and PDFs usually open normally even when their names look broken. If you need the correct names, ask the sender to rename the files using plain letters and numbers, or to re-create the archive in another format such as 7z.

When it is really RAR, 7z, split or password protected

Touch and hold the file in Files, choose Get Info and check the extension. A .rar or .7z cannot be extracted by Files, and split or password-protected archives each need their own steps:

Files that are too big, or links that expired

Gmail has a limit on attachment size, and larger files may arrive as a Google Drive link instead of an attachment. In that case you save the file from the link, not from the email. Many messaging apps also keep files only for a limited time, after which they can no longer be downloaded. Neither problem can be fixed on the receiving side, so ask the sender to send the file again or share it another way.

Checklist, top to bottom

  1. Is it saved in the Files app?
  2. Is the file size roughly what the sender expected?
  3. Does the name end in .zip, and not .rar, .7z, .z01 or .part1?
  4. Is it asking for a password?
  5. Has the file or link expired?
  6. If only the names are garbled, do the files themselves open?

Most problems are solved by the first three questions. If you reach the end of the list and the file still will not open, ask the sender to check that the archive opens on their side before sending it again.

Frequently asked questions

Can I see what is inside a ZIP directly in Gmail?

Gmail usually cannot preview ZIP contents. Save the attachment to Files with the share button and open it there.

I saved it, but I cannot find it.

In the Files app, open Browse and check both On My iPhone and iCloud Drive, or type the file name into the search field.

Does garbled text mean the file is broken?

Usually not. In most cases only the displayed file names are wrong; the contents are intact.

Do I need an extra app for a normal ZIP?

No. A regular .zip opens in the built-in Files app with a tap. An extra app is only needed for RAR, 7z, split archives or some encrypted files.
