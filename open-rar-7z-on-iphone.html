How to open RAR and 7z files on iPhone

Short answer: if the file ends in .zip, you do not need another app. The built-in Files app extracts it when you tap it. RAR and 7z are different: Files cannot extract them, so you need an extractor app that supports those formats. This guide shows how to confirm the file type, how to use Files for ZIP, and how to open RAR and 7z when Files is not enough.

Step 1: check the file extension

A surprising number of “won’t open” files turn out to be ordinary ZIP files. The Files app sometimes hides the extension, so check it before installing anything:

  1. In Files, touch and hold the file.
  2. Choose Get Info.
  3. Look at the name or kind and note whether it ends in .zip, .rar, .7z, .tar.gz or something else.

ZIP: use the free, built-in method first

For a plain .zip file there is nothing to buy or install:

  1. From Mail or Safari, use the share sheet and choose Save to Files. Save it to On My iPhone or iCloud Drive.
  2. Open the Files app and tap the .zip file.
  3. A folder with the same name appears next to it. Open that folder to see the contents.

If tapping does nothing or shows an error, the file is probably not a regular ZIP. It may be a RAR or 7z that was renamed, a split archive, a password-protected ZIP, or a download that never finished.

Why RAR and 7z do not open

The Files app handles a limited set of archive formats, and RAR (including RAR5) and 7z are not part of it. The file is not damaged; the phone simply has no built-in way to decompress it. If you are at a computer you can extract it there, but if all you have is your iPhone, an extractor app that reads RAR and 7z is the quickest route.

There are several extractor apps on the App Store. A few things are worth checking before you pick one:

  • Does it support the exact format you have, such as RAR5 or 7z?
  • Can it handle split archives and password-protected archives?
  • Does it process files on the device, or does it upload them somewhere?
  • Are there so many ads that they get in the way of opening your own file?

Still not opening? Work through this list

  • The file size looks far too small: the download probably stopped early. Save it again.
  • The name ends in .part2.rar or .7z.002: it is one piece of a split archive. Put every part in the same folder (see how to extract split archives).
  • You are asked for a password: ask the sender for it (see opening a password-protected ZIP).
  • It came from Gmail and will not open: see ZIP from Gmail won’t open on iPhone.

One more tip: if a file opens but the names inside look like random symbols, the archive was probably created on a computer that used a different character encoding. The contents are usually fine; asking the sender to re-create the archive, or to use 7z, normally fixes the names.

Frequently asked questions

Can an iPhone open RAR files without a computer?

Not with the built-in Files app. An extractor app that supports RAR lets you open them on the iPhone itself.

What is the difference between 7z and ZIP?

Both are archive formats, but 7z uses different compression methods that the ZIP support in Files cannot read. You need an app that supports 7z.

Is it safe to hand files to an extractor app?

It depends on the app. Zipbox makes no network requests and processes everything on the device. For other apps, read their privacy details on the App Store.

Where do the extracted files go?

They are extracted inside the app first; from there you can export them to Files or iCloud Drive with the share sheet.
